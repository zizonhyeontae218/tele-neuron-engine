## Reference retirement

Preservation tags use the same names as the nine original backup branches.
Six model tags already exist; the master, Claude and iPad original-head tags
are added without moving existing tags. After main integration is verified,
only the nine audited backup branches are deleted. The GitHub connector publishes the merge tree because this runtime has no direct
Git push credential. The scoped [retirement workflow](../../.github/workflows/retire-backup-refs.yml)
then creates the missing tags and retires only these refs using its job token.
It runs on the authorized main publication marker or manual dispatch, and can
be rerun idempotently.

The deletion push is atomic
and checks the server-advertised old SHA for each branch. New concurrent work
causes refusal. No force push, protected-ref bypass or history rewrite is used.

The original six-model cleanup command remains idempotent after this retirement:
a missing safety branch is accepted only if the original model branch is already
absent and its immutable preservation tag still matches. A changed safety ref,
changed original model branch or conflicting tag still stops the command.
