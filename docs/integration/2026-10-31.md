## Follow-up: GitHub-hosted cleanup

A manual-only workflow `.github/workflows/archive-endophalon.yml` now lets the
repository owner finalize cleanup on GitHub without a local checkout or PAT.
It uses the job-scoped GITHUB_TOKEN with contents:write. No new user credential
or repository setting is created. Run on master from the Actions page.

`scripts/archive_endophalon.py` defaults to a read-only preview. The workflow
then applies the fixed six-branch allowlist from original-heads.json: checks
safety refs and archive/master ancestry; creates missing backup tags atomically;
verifies all six tags remotely; deletes only unchanged original model branches
in another atomic push. A pre-push guard checks the server-advertised old OIDs
to reject concurrent new work without any force option. Re-running is safe.
Existing safety branches, working branches, master and archives are retained.

This workflow is prepared, not dispatched automatically. Actual cleanup remains
pending until its manual run succeeds. The original connectivity blocker above
describes the previous direct Git/API approach, not an Actions limitation.
