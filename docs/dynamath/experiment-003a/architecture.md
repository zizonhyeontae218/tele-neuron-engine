# 003a architecture and boundaries

The code imports the existing Model1 parameter layout and Session. The runtime still executes F1 through F9 in order, admits at most one queued token at the first tick in each three-tick block, checks output only at ticks two and three, enqueues actual emissions as FIFO feedback, and carries one shared S and one writable scalar m. No token-specific network or retrieved answer is introduced. Training follows the unchanged 002 schedule, including second-check SILENCE supervision; it is not equivalent to closed-loop generation. The discrepancy is not repaired by this experiment.

For formula i, zᵢ = 1.5 tanh(dᵢ)⊙S + tanh(SVᵢ+bᵢ+mQᵢ)Uᵢ+cᵢ+mRᵢ. Candidate fᵢ uses the validated tree and S′=(1−aᵢ)⊙S+aᵢ⊙fᵢ, aᵢ=.05+.9σ(leakᵢ). The AST leaf `z` **means tanh(z)**, `S` means tanh(S), and `m` means tanh(m), ensuring bounded leaves; each operator preserves [-1,1]. A learned coefficient is tanh(αᵢ) and is separate from runtime m. This bounded-leaf convention must be considered when reading tree representations. The residual insertion `clip(tanh(z)+tanh(α) sin(tanh(S)),−1,1)` is exactly the old law at α=0. Other catalog selections are not identity-initialized, and are separately labeled.

The deterministic generator, typed validator, tree mutation primitives and generic successive-halving engine are separate. The executed pilot uses a small screening stage and one mutation/continuation stage, with CE-only selection; it is not the full 96/16/4 competition. `search.race` supports cumulative-budget stages and refuses unequal interrupted budgets, but the pilot runner does not yet wire it to a full multi-stage run or multidimensional final selection. Subtree swap is currently a donor-subtree replacement, not a reciprocal two-parent crossover. Algebraic equivalence beyond commutative canonicalization and simple equal-child checks is not exhaustively removed. The numerical probe covers finite test values and does not protect a model already given NaN inputs.

English examples pair utterances (0,1), (2,3), etc. in original speaker order, and keep S and m through pairs within one dialogue; masks reset them at new dialogue boundaries. The batched stream's absolute law phase continues across lane resets rather than restarting F1 separately per dialogue; this is an identified limitation of the training/evaluation batching and must be corrected before claiming fully independent per-dialogue clocks. Checkpoint inference uses the original Session, with a fresh clock for a new Session. Korean pilot reuses 002's concatenated pair streams; it does not test dialogue-level reset semantics.
