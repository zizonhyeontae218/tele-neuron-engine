# DynaMath 003aa — 한국어 장기 학습

003a가 사용한 002a Model1의 누적 18,000스텝 체크포인트에서 시작했습니다.
동일한 한국어 Q/A 512쌍과 고정 수식을 사용해 Windows PC에서
**추가 500,000 업데이트**를 완료했습니다. CPU PyTorch 2.12.0, 배치 8,
TBPTT 8슬롯 및 Adam 학습률 0.0002를 사용했습니다.

| 추가 스텝 | 훈련 응답 CE | 검증 응답 CE |
|---:|---:|---:|
| 3,000 | 1.53158 | **1.59608** |
| 50,000 | 1.28973 | 1.71289 |
| 500,000 | 0.94068 | 2.44308 |

3,000스텝 모델을 재현해 당시 검증 CE와 정확히 일치함을 확인했습니다.
50만 스텝 모델에서 한국어 수식 후보 50개를 64/400/2,000스텝의 단계별
예산으로 비교했습니다. F1-31의 테스트 응답 CE는 고정 수식 대조군
2.45062에서 2.22816으로 낮아졌고 실제 생성 EOS는 15/24에서 11/24로
줄었습니다. 3,000스텝 모델에서 출발한 별도 2,000스텝 동등 예산 비교는
고정 수식이 검증 CE 1.61857, F1-31이 1.65805였습니다. 이름 회상은
모든 조건에서 0/8이었습니다.
