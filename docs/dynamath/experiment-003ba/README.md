# DynaMath 003ba — 한국어 수식 50개 비교

003aa와 동일한 002a Model1 출발점에서 **F1 수식 50개 × 10,000스텝**
총 **500,000 업데이트**를 순차 실행했습니다. 각 후보는 같은 512쌍의
한국어 학습 자료와 같은 스텝 예산을 받았습니다. 3,000·10,000스텝에서
검증을 수행했고, 검증 기준으로 후보를 고정한 뒤 테스트를 수행했습니다.

| 시점 | 후보 | 후보 테스트 응답 CE | 고정 수식 테스트 응답 CE |
|---:|---|---:|---:|
| 3,000 | F1-29 | 1.59922 | **1.59850** |
| 10,000 | F1-19 | 1.61150 | **1.61138** |

실제 생성 테스트에서 모든 비교 모델은 EOS 24/24, 이름 회상 0/8이었습니다.
원래 512쌍이 모두 라벨 0임을 확인한 뒤, 라벨·길이로 층화한 512쌍
(라벨별 171/171/170)과 두 수식을 3,000스텝 예산으로 교차 비교했습니다.
균형 표본의 고정 수식은 동일 답변 쌍을 22/48에서 17/48로 줄였으나
전체 검증 CE는 1.59608에서 1.60387로 올라갔습니다. 라벨과 토큰 길이를
맞춰 질문을 교체한 48쌍에서 네 조합 모두 정답 로그확률 이득의
95% 부트스트랩 구간에 0이 포함됐습니다. 이 비교는 단일 시드와 한 분할을
사용했습니다.
