# Endophalon 3 (AB alpha) — 명령으로 선택하는 A/B와 공유 물리 기억

상태: 2026-11-02 구현 기준. 소유자는 기존 모델을 3T, 이 AB alpha를 3으로 명명하고 구현 시작을 지시했다. 검증 결과는 별도 구현 보고서에 기록한다. 이전 3-AB 단일-head 실험은 원본과 실패 결과를 보존한다. 이 초안은 그 실험의 성능을 개선했다고 주장하지 않는다.

## 소유자가 제시한 방향

A와 B를 각각 ProMax 형태의 독립 모듈로 두고, 입력 명령에서 사용할 모듈을 선택한다. 한 물리계를 공유해 A에서 생긴 기억을 B가, B에서 생긴 기억을 A가 사용할 수 있게 한다. A와 B의 출력을 하나의 학습 head로 합칠 필요는 없다.

확정한 경계:

- 물리 공간과 실행 중 상태는 하나다. 위치·속도, 시뮬레이션 시각과 난수 발생기 상태를 공유한다.
- A/B별 readout과 readout의 학습 통계(mean/scale/weights)는 따로 둔다.
- A 모듈은 기존 A의 4개 연산, B 모듈은 기존 B의 8개 연산을 유지한다. 연산별 head로 확장하지 않는다.
- 명령 해석기가 A/B를 결정한다. 각 모듈 내부의 opcode에 따른 물리 연산은 ProMax와 같은 역할을 맡는다.
- 144노드, 2 substeps, 기존 16 readout zones의 관측 예산과 delay 12를 유지한다. 16 zones를 head별로 자동 증설하지 않는다.
- A/B 전환만으로 상태를 초기화하거나, 과거 상태를 따로 저장했다 되돌리거나, 이벤트를 추가하지 않는다.

## 결정이 필요한 물리 파라미터 경계

이번 구현은 A/B 파라미터 전환 안을 따른다. 위치·속도는 그대로 유지하고 질량·강성·anchor 변경에 따른 즉시 운동/탄성 에너지 차이를 기록한다. 이것은 외부에서 제어하는 파라미터 전환이며 에너지 보존 주장이 아니다. 아래 표는 대안 비교 기록이다.

| 항목 | A/B 물리 파라미터도 전환 | 공통 물리 파라미터 고정 |
| --- | --- | --- |
| 위치·속도와 기억 | 공유·연속 | 공유·연속 |
| A/B 입력 설정·head | 분리 | 분리 |
| 감쇠·강성·bath 등 | 선택된 프로필 사용 | 하나의 값 사용 |
| 기존 카드 사용 | 전환 상태 분포에서 재검증 필요 | 서로 다른 기존 theta를 그대로 동시에 적용할 수 없음 |
| 추가로 정할 계약 | 질량 등 전환 시 상태·에너지 처리 | 공통 theta 학습과 A/B 균형 평가 |

기존 A/B seed-1 카드도 감쇠, 강성, 질량 분포, bath가 다르다. 파라미터를 전환하는 안은 단순 head 선택과 다르며, 질량 변경 시 속도 유지와 운동량 유지 중 무엇을 택하는지 명시해야 한다. 상태 연속성과 에너지 보존을 동시에 달성했다고 추정해서는 안 된다. 고정 파라미터 안에서는 각 모듈의 전용 head를 유지해도 물리계는 공통 학습 대상이 된다. 두 안 모두 기존 분리 모델의 정확도가 그대로 유지된다는 보장은 없다.

## 명령과 실행 계약

기존 표기 `A XOR 1 0`, `B recall1 0 0`를 명령 해석기가 처리한다. `level A` / `level B`를 별도 표기로 제공하더라도 다음 데이터 명령에 A/B를 붙이는 문법 설탕으로 해석하며, level 선택 자체가 물리 입력 이벤트나 추가 시간 경과가 되지 않게 한다.

1. 명령의 level/op/data와 허용 연산을 검증한다. 잘못된 명령은 상태와 시간을 바꾸기 전에 거부한다.
2. 이번 이벤트의 A/B 모듈을 확정하고 해당 입력 설정으로 opcode와 데이터를 자극으로 넣는다.
3. 현재 공유 상태에서 연속 적분한다. 매 이벤트마다 jitter나 warmup을 다시 적용하지 않는다.
4. delay 12에서 16-zone 특징을 관측한다.
5. 해당 이벤트에 확정된 A 또는 B head와 그 head의 정규화 통계로 출력을 계산한다.
6. 갱신된 상태와 난수 진행 위치를 다음 이벤트에 넘긴다. 출력 비트를 다시 입력으로 주입하지 않는다.

alpha는 기존 regular gap 16을 유지한다. 모듈 전환은 이벤트 경계에서만 허용하고, 진행 중 pulse나 readout 도중 파라미터를 바꾸지 않는다. 외부 명령에 의한 모듈 선택과 학습된 물리 내부 opcode 처리를 문서에서 구분한다.

## 공유 기억의 의미

기억 기준은 모듈별 마지막 입력이 아닌 **전체 데이터 이벤트 이력**이다. A/B가 바뀌어도 recall1은 직전 이벤트의 a, recall2는 두 이벤트 전의 a를 대상으로 한다. level 선택 명령 자체는 이력에 들어가지 않는다. 기억 정답 계산은 테스트 oracle에서만 하며, 실행 head에 과거 정답 비트를 직접 제공하지 않는다.

이전 이벤트가 하나 이상 존재하는 상황에서:

| 데이터 명령 | 기대 동작 |
| --- | --- |
| `A XOR 1 0` | A head가 현재 XOR의 결과 1을 출력 |
| `B recall1 0 0` | B head가 직전 A 이벤트의 a=1을 기억해 출력 |
| `A recall2 0 0` | A head가 두 이벤트 전 A 이벤트의 a=1을 출력 |

이 예의 1은 XOR 출력의 자동 전달이 아니라 원래 입력 a를 기억한 것이다. 결과를 다시 입력으로 쓰는 프로그램 실행은 별도 기능이며 alpha에서 암묵적으로 추가하지 않는다. 시작 직후 이력이 부족한 이벤트의 평가는 기존 washout 정책을 따른다.

## 구현 순서와 파일 책임

현재 구현 단계의 책임 배치는 다음과 같다.

- `src/tele_neuron/endophalon3_alpha/`: 기존 패키지를 덮어쓰지 않는 별도 alpha 모듈. `session.py`는 공유 상태·clock·RNG, `session.py`의 dispatch는 명령 검증과 이벤트별 모듈 선택, `model.py`는 A/B 입력 설정과 두 head를 소유한다.
- 기존 적분기에서 상태 초기화와 적분 실행을 분리할 때, 무전환 실행이 기존 엔진과 일치하는 회귀 검증을 먼저 한다. 기존 `run()`은 호출마다 초기화하므로 명령별로 반복 호출하는 것만으로 상태 공유를 구현할 수 없다.
- `tests/test_endophalon3_alpha.py`: 전환 시 상태 보존, 무전환 동등성, 잘못된 명령의 무변경, 명령/데이터 이벤트 경계, RNG·checkpoint 재개 동등성을 검증한다.
- alpha 모델·로그·평가 자료는 별도 디렉터리에 저장한다. 기존 3-A/3-B, 단일-head joint 모델은 보존한다.

## 학습 전 최소 검증

1. A-only / B-only 실행에서 각 모듈이 해당 설정의 기준 실행과 일치하는지 확인한다.
2. 동일한 명령열을 한 번에 실행한 결과와 이벤트별로 이어 실행한 결과를 비교한다.
3. A→B, B→A 직후 첫 두 이벤트, 교대 전환, 긴 블록 뒤 전환을 별도로 측정한다.
4. 다른 과거 입력 뒤 같은 현재 명령을 넣는 쌍을 구성해 전환을 넘어선 recall1/recall2를 검사한다. 전환 때 reset하는 대조군도 함께 측정한다.
5. no-reset / reset 대조군은 구현상 상태 보존과 측정된 기억 정확도를 구분한다. head 선택이 올바르다는 테스트만으로 기억 성능을 주장하지 않는다.

장기 재학습은 위 검증 및 물리 파라미터 경계 확정 이후 별도 계획으로 정한다. A/B head는 train의 해당 모듈 이벤트로 각각 적합하고 validation은 수준별·연산별로 평가한다. 전환을 포함한 전체 스트림을 train/validation/test 단위로 분리한다. 기존 확인 세트 10000–10015와 20000–20063은 이미 관측됐으므로 새 alpha의 미사용 확인 세트라고 부르지 않는다.

성능 목표는 A/B 각각 전체 >=90%, 각 연산 >=85%를 후보 기준으로 유지하되, 고정-level 성능과 전환 직후 성능을 따로 보고한다. 총 학습 예산과 새 확인 데이터는 실행 전에 확정한다. 현재 설계만으로 목표 달성이나 ProMax 수준 성능을 보장하지 않는다.

## 이름과 관측 예산

기존 `src/tele_neuron/endophalon3/` 및 기존 카드의 family 문자열은 재현 호환을 위해 유지하며 현재 명칭은 3T다. 새 모듈 `tele_neuron.endophalon3_alpha`의 family는 Teleneuron-Endophalon-3이다. 새 `tele_neuron.endophalon3t` CLI는 이전 학습 CLI의 이름 alias다. A/B 각각의 기존 관측점 16개를 저장하되 매 이벤트에는 선택된 뱅크의 16개만 관측한다. 따라서 관측 연산 수는 16, 저장된 관측 설정은 두 벌이며 그 용량 차이를 보고한다.
