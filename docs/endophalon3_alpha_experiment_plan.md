# Endophalon 3 MVP evaluation plan — 2026-11-02

Before execution: exactly one predeclared pair, former 3T A-binary seed 1 and B-binary seed 1. No outer search, new theta or seed replacement. Runtime selects each bank's complete input/physical/observation profile; independent head fits use training events from that level only. The old heads are evaluated as a reference. A pooled linear head fitted on the same training observations is an explicit diagnostic control, not the production model or a reproduction of the older single-theta joint experiment.

Freeze new AB stream IDs: train 30000–30023, validation 30024–30031, test 30032–30063, confirmation 30064–30127; physical/data seed 1, 64 events, washout 4, whole-stream split. New IDs were chosen before this evaluation; previously viewed 3T confirmation IDs are not reused. Fit one A and one B Ridge head, with original alpha 1, mean/scale fitted on train only; no validation or test coefficient selection.

Report level/operation metrics and first/second events after switches. Reset control uses identical instructions and fitted heads but resets positions and velocities to their original jitter states whenever the bank changes, keeping elapsed time and RNG continuous and adding no warmup. This is a state-ablation control, not a reset model trained on a different distribution. Compare recall1/recall2 explicitly, including adverse or null effects. Parameter switch changes in stored mechanical energy are recorded rather than hidden.

Reproduce once to a new directory: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python scripts/evaluate_endophalon3_alpha.py --output-dir <new-directory>` after installation. The script rejects existing outputs and creates model/head bundle, per-stream observations and metrics, plus a SHA-256 manifest. Original cards/configs/source/evidence remain immutable. This bounded MVP establishes implementation behavior and measured readout adaptation; it does not train physical parameters or imply the >=90% per-level / >=85% per-operation goals have been achieved.
